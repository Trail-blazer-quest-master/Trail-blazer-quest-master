## Featured Projects

### Ga₂O₃ Radar Systems Under Thermal Constraints

A MATLAB-based system-level study comparing Ga₂O₃ and GaN radar performance under thermal, frequency, efficiency, and receiver-noise constraints.

The study combines radar range modeling with detection probability analysis using the Marcum-Q formulation. It examines how transmit power and operating frequency affect system performance, and considers the impact of thermal limits and receiver sensitivity.

**Key observation:** Higher theoretical power capability does not automatically produce better continuous-operation radar performance when thermal constraints are included.

**Methods and topics:** MATLAB · Radar range equation · Marcum-Q detection probability · Parameter sweeps · Sensitivity analysis · Ga₂O₃/GaN comparison

### Real-Time Sleep Apnea Detection Using Raspberry Pi

Developed a Raspberry Pi-based system for respiratory audio acquisition, signal analysis, and real-time detection.

The work involved signal-processing concepts and embedded-platform implementation, with testing and iterative debugging during development.

**Methods and topics:** Raspberry Pi · Audio acquisition · Signal processing · Embedded implementation · Testing and debugging

### High-Bandwidth mmWave Microstrip Antenna on Silicon Carbide

Designed and analyzed a high-frequency microstrip antenna using a Silicon Carbide substrate.

The project investigated antenna radiation characteristics and impedance performance through MATLAB-based electromagnetic analysis.

**Methods and topics:** MATLAB · Antenna analysis · mmWave · RF engineering
