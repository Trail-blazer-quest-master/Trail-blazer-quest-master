## Selected Projects

### Ga₂O₃ Radar Systems Under Thermal Constraints

A MATLAB-based study comparing Ga₂O₃ and GaN radar performance under thermal, frequency, efficiency, and receiver-noise constraints.

The work brings together radar range modeling, detection probability analysis using the Marcum-Q formulation, and parameter sweeps across transmit power and frequency.

**What I explored:**

- How thermal limits affect sustained radar operation
- Why higher theoretical power capability does not automatically mean better system-level performance
- How receiver sensitivity and noise influence detection performance
- How power and frequency interact in radar analysis

**Topics:** MATLAB · Radar systems · Thermal constraints · Detection probability · Sensitivity analysis

### Real-Time Sleep Apnea Detection Using Raspberry Pi

Worked on a Raspberry Pi-based system for respiratory audio acquisition, signal analysis, and real-time detection.

The project explored embedded implementation and signal processing, along with testing and iterative debugging.

**Topics:** Raspberry Pi · Audio signal processing · Embedded systems · Real-time analysis

### High-Bandwidth mmWave Microstrip Antenna on Silicon Carbide

Designed and analyzed a high-frequency microstrip antenna using a Silicon Carbide substrate, with MATLAB-based electromagnetic analysis.

The work explored antenna radiation characteristics and impedance performance.

**Topics:** MATLAB · Antenna analysis · mmWave · RF engineering

### IoT and Embedded Hardware Projects

Built and tested microcontroller-based prototypes involving sensors, communication modules, and embedded control.

The project work covered circuit design, programming, functional testing, debugging, and system integration.

**Topics:** Microcontrollers · Sensors · Prototyping · Embedded control
